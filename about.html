About Me

My Journey

Welcome!

I'm an aspiring game developer who enjoys programming, designing characters, and creating interactive game worlds.

My interest in game development comes from enjoying games that encourage exploration, survival, building, creativity, and storytelling.

Learning Game Development

I've been learning to create games using Godot 4, working with both 2D and 3D projects.

Throughout my projects, I've practiced character movement, animations, game physics, enemy behavior, level design, and combat systems.

My Favorite Part of Game Development

One of my favorite parts of creating games is bringing original characters and environments to life.

I enjoy creating fantasy creatures, designing interesting worlds, and thinking of new ways players can interact with those worlds.

My Future Goals

My goal is to continue improving my programming and game design skills so I can eventually create larger original games.

I'm especially interested in games involving exploration, survival, creature collecting, and immersive storytelling.
