About Me

Welcome to my Game Developer Portfolio! I am a student who enjoys learning about game development, programming, and creating fantasy worlds.

I enjoy designing characters, creating game environments, and learning how different game mechanics work together. My goal is to continue improving my skills while developing games that other people can enjoy.

My Game Development Journey

I started learning game development by following tutorials and completing smaller projects. Each game has helped me learn something different about programming, physics, level design, and game mechanics.

My first project was a mini golf game, where I practiced controlling the ball, using physics, and progressing through different golf holes.

My second project was a 3D flying game. I learned how to work with a 3D environment, create obstacles, and track the player's distance and speed.

My third project was a fantasy wolf platformer. This project allowed me to work more creatively by designing my own wolf character, adding enemies, building levels, and creating a boss battle.

As I continue learning, I hope to create larger and more detailed games while developing my programming and design skills.
